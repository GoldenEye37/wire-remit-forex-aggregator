**Phase:** Foundation (Week 1)  
**Status:** 🟡 In Progress

**Estimated Time:** 2-3 days

## 📋 Overview

Implement custom metrics recording across all application endpoints and services using OpenTelemetry metrics API.

## 🎯 Objectives

1. Record request metrics for all API endpoints
2. Track authentication success/failure rates
3. Monitor rate fetching operations per provider
4. Track rate aggregation performance
5. Ensure metrics are exportable to Prometheus

## 📊 Metrics to Implement

### HTTP/API Metrics
- `api.requests.total` (Counter) - Total API requests
- `api.request.duration` (Histogram) - Request duration in ms
- `auth.attempts.total` (Counter) - Authentication attempts

### Business Metrics
- `forex.rate_fetches.total` (Counter) - Rate fetch attempts
- `forex.provider_errors.total` (Counter) - Provider errors
- `forex.rates_aggregated.total` (Counter) - Total rates aggregated
